# Leonida Spotter

An unofficial, interactive GTA VI map of collectibles and secrets across Leonida: collectible cards, hidden and rare cars, Kenton's treasures, meteorite chunks, WAiNK scans, easter eggs, secret quests, unique weapons, and the shops where you sell loot.

## Run it

```bash
npm start
```

Then open http://localhost:5173. There are no dependencies to install. Leaflet and the clustering plugin load from a CDN.

## Features

- **Pause-menu style UI**: a full-screen map with a top bar (Map, Collections, Settings), overall completion %, a left index panel, a right-hand info card, control hints, a notification feed, a "Collected" splash and a loading screen with tips. All icons and art are original, inspired by the game's Vice City sunset look.
- **Blips**: a round icon set (`js/icons.js`) with one glyph per category, plus special ones (UFO, Bigfoot, ghosts, playlists, trophies…). Clusters show a ring coloured by the categories inside. You can pick small, medium or large blips.
- **Two map styles**: Night and Atlas, both generated by `tools/build-map.mjs` with street grids, causeways, the airport, port, Keys causeway, swamp channels, farmland, contours and railways.
- **My map**: load your own map image (an in-game screenshot or the official poster you saved), click 4 known places, and every pin is carried across with a least-squares affine fit. The image stays in IndexedDB and is never uploaded.
- **Index**: category toggles with found/total counts. Alt- or Ctrl-click a category to show only that one. Search with `/`, a region filter, and a hide-found toggle.
- **Info card**: how to find each item, what it needs, the reward, conflicting sources and source links. Actions: Mark found (F), Waypoint (W), Move (M), Copy link.
- **Waypoints**: right-click anywhere, or press W on a selected blip.
- **Collections tab**: progress per category, plus per-set progress for cards. Click a set to filter the map to it.
- **Add pin (A)** and **Move**, with progress kept per map style. Export and Import save everything to JSON.
- Shareable deep links (`#/item/<id>`) and a mobile layout with bottom sheets.

Keys: `1` `2` `3` switch tabs, `/` search, `A` add pin, `F` / `W` / `M` act on the selected blip, `Esc` goes back.

Everything you do is saved in your browser (localStorage, plus IndexedDB for a custom map image).

## Accuracy: read this

- The base maps (`assets/map-night.svg`, `assets/map-atlas.svg`) are **original, schematic drawings** of Leonida, generated by `tools/build-map.mjs`. They are not Rockstar's map. For exact positions, use the **My map** mode with your own image. Town and district positions come from written descriptions of the official map, such as "Hamlet is south-west of Vice City".
- Pins are placed by hand from **written guide descriptions**. They point to the right area, not exact in-game coordinates. Entries marked `conf: 'guess'` are places that aren't on the map yet, pinned in the most likely area.
- Data was compiled in the week after launch, from fan guides that sometimes disagree. Conflicts are flagged in each popup.

```
tools/test-transform.js tests for the alignment math (npm test)
server.js             zero-dependency static server
```

## Adding or fixing locations

1. If the place isn't in `data/places.js` yet, add it: `'key': [x, y, 'Label', tier, 'region']`. The map is 1000 x 1400 units and y points down. The coordinate readout in the bottom-left corner of the map shows the x/y under your cursor.
2. Add the entry to `data/locations-more.js` (or `data/locations.js`) with the matching helper, for example:
   ```js
   card('Vice City Narcos', 'Kyle Lewicki', 'dynamix', 'Rear corridor bench.', 'xtreme');
   car('Gold Rolls-Royce', 'san4san-studio', 'Middle of the garage.', 'detonated', { req: 'Clear the location' });
   ```
   Optional fields: `d: [dx, dy]` nudge, `req`, `reward`, `sub`, `conflict`, `conf: 'guess'`.
3. Run `npm run check`.

Pins you moved in the browser are in the `overrides` section of an export, keyed by item id. To make a fix permanent, copy those x/y values back into the data.

## Adding a tiled map (with permission)

`data/basemaps.js` lists optional tiled base maps, the kind made of square images loaded as you zoom. It ships empty. Add an entry **only** for tiles you're allowed to use: your own, an openly licensed set, or a map whose owner has agreed in writing. Keep the credit line they ask for in `attribution`.

1. Add the entry (`id`, `name`, `url` with `{z}/{x}/{y}`, `attribution`, `width`/`height` at tile zoom 0, zoom limits). The comments in the file explain each field.
2. Open the site, go to Settings > Map style, and pick the new button. With no alignment yet, it asks you to click Port Gellhorn, Downtown Vice City, Key Lento and Mount Kalaga.
3. Choose **Copy alignment** and paste the `calib: { T: [...] }` line into the entry, so every visitor gets aligned pins.
4. Commit and push. GitHub Pages picks it up automatically.

Pin fixes made with **Move** are stored per map, so fixing a pin on a tiled map doesn't move it on the schematic maps.

### More anchors = more accurate pins

With only the 4 required anchors, the alignment is a straight stretch-and-rotate, so pins far from those 4 places can be noticeably off. **Add anchors** (Settings, while the tiled map is showing) keeps your existing points and asks for about 20 more places: the airport, Ocean Beach, Hamlet, Lake Leonida, towns and islands. A dashed ring shows where the pins currently think each place is. Click the real spot, or Skip if you're unsure, and press Done whenever you like.

With 5 or more anchors the alignment becomes a smooth local warp (a thin-plate spline, in `js/transform.js`). Every anchor lands exactly where you clicked, and the pins around it are corrected too. Then **Copy alignment** and paste the line (now with `pts: [...]`) into `data/basemaps.js`.

`npm test` checks the math: exact anchors, a working reverse mapping, and lower error as anchors are added.

## Using a real map image

In Settings, choose **Load image** under "Use your own map image". Then click Port Gellhorn, Downtown Vice City, Key Lento and Mount Kalaga on it. Pins are carried across with an affine fit. Because the schematic map isn't a perfect linear copy of the real one, some pins will be a little off: use **Move** to fix them. Those fixes are stored separately from the schematic-map fixes and included in Export.

Don't publish Rockstar's map art with a public deployment of this site unless you have the rights to it. The image-loading feature keeps it local for that reason.
